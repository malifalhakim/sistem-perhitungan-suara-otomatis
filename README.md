# 📝 Automated Vote Counting System for Indonesian C1 Election Form

## Description
This website is an automatic vote counting system for elections that utilizes OCR and Object Detection technologies. You can upload an image of a C1 form or use one of the provided sample images, and then view the model's reading results.
